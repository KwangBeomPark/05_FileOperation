# 📁 FileOps Hub: 팀 간 업무 자료 배분 및 자동 동기화 관리 허브

> **부서 간 업무 자료 배분 · 스케줄 기반 자동 동기화 · 중복 파일 정리 및 협업 누락 방지**

**FileOps Hub**는 사내 여러 부서와 팀 간의 업무 자료 배분 및 폴더 동기화를 자동화하여, 팀 간 원활한 자료 공유와 업무 누락 방지를 돕는 데스크톱 관리 도구입니다.

업무가 여러 팀에 걸쳐 진행될 때 동일한 파일이 중복 보관되거나 버전이 달라 업무 차질이 발생하는 경우가 많습니다. FileOps Hub는 유관 부서 폴더와 공용 드라이브 간의 양방향 동기화 및 자동 배포를 지원하여, 최신 업무 자료와 품의서를 누락 없이 공유하고 불필요한 중복 파일을 체계적으로 정리할 수 있도록 돕습니다.

## 운영 목적

1. **팀 자료 배포 허브**: 유관부서 폴더와 영업/관리자 공용 폴더 사이에서 최신 파일을 양방향으로 동기화합니다.
2. **저장소 호환 포맷 변환**: Excel, PowerPoint, Word, PDF를 대상 저장소가 허용하는 형식으로 변환하면서 파일 수정 시간을 보존합니다.
3. **정산 자료 전처리**: PDF와 EML(이메일)을 고해상도 이미지로 일괄 렌더링하고, 이미지 OCR로 프로모션 번호를 추출하여 파일명을 체계적으로 정리합니다.
4. **예약 실행과 결과 통지**: 앱이 실행 중이면 지정 시각 이후 하루 한 번 통합 작업을 실행하고, 성공·부분 실패 내역을 담당자 이메일(SMTP)로 자동 보고합니다.

> 본 앱은 네트워크 드라이브나 SharePoint의 Windows 접근 권한을 임의로 변경하지 않으며, 현재 로그인한 Windows 사용자가 접근 가능한 경로만 안전하게 처리합니다.

---

## 주요 기능

1. **Tasks (통합 실행 및 예약)**: 활성화된 각 탭의 작업을 순차적으로 통합 실행하고, 매일 특정 시간에 작동하도록 예약할 수 있습니다. 작업 완료 후 담당자에게 SMTP 이메일로 결과를 보고하며, 메일 발송 실패 시 로컬 보고서를 남깁니다.
2. **Sync (폴더 동기화)**: 양방향 최신본 동기화 또는 첫 번째 원본 폴더에서 대상 폴더로 단방향 배포합니다. 하위 폴더 포함과 제외 패턴을 선택할 수 있으며, 구버전 백업 보존 옵션을 제공합니다.
3. **EML (메일 이미지화)**: 등록한 소스 폴더 내의 EML(이메일) 파일들을 PNG 이미지로 일괄 변환하며, 변경 사항이 없는 파일은 자동으로 건너뜁니다.
4. **PDF (PDF 이미지 변환)**: 선택한 PDF 문서의 모든 페이지를 JPG 이미지로 렌더링하여 정산 및 검수에 활용할 수 있게 합니다.
5. **OCR (텍스트 추출 및 리네임)**: 이미지화된 파일에서 OCR(광학 문자 인식)을 통해 프로모션 번호를 추출하고, 중복 충돌을 방지하며 파일명을 깔끔하게 정리합니다.
6. **Convert Files (문서 포맷 변환)**: Microsoft Office COM을 활용하여 Excel/PowerPoint/Word 문서를 변환하고 PDF를 ZIP으로 패키징합니다. 원본 백업 이동 및 안전 복구 모드를 지원합니다.

## 🚀 다운로드 및 설치

1. GitHub의 **[Releases](https://github.com/KwangBeomPark/05_FileOperation/releases)** 탭으로 이동합니다.
2. 공식 설치 프로그램 **`App05_FileOps_Setup_vX.Y.Z.exe`** (및 매니페스트 `build-manifest.json`, 체크섬 `SHA256SUMS.txt`)를 다운로드합니다.
3. 설치 프로그램을 실행합니다 (UAC 관리자 권한 없이 사용자 프로필에 안전하게 설치됩니다).
4. Windows 시작 시 자동 실행(`--tray`) 옵션을 지원하여 백그라운드 무인 예약 작업을 수행할 수 있습니다.
