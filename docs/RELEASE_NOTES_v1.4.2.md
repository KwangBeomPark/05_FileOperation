# FileOps Hub v1.4.2 — App005_FileOps

## 변경 사항

- 관리 번호를 005로 통일했습니다. 앱은 `App005_FileOps.exe`, 설치 프로그램은
  `App005_FileOps_Setup_v1.4.2.exe`, 선택적 런처는 `App005_FileOps_Launcher_v1.4.2.exe`입니다.
- 기본 설치 경로는 `%LOCALAPPDATA%\Programs\FileOps`입니다. 설치 화면에서 경로를
  확인할 수 있고 이전 설치 위치를 자동으로 기본값으로 재사용하지 않습니다.
- 설정·로그·수동/예약 실행 이력은 설치 폴더 안의 `UserSetting`에 모았습니다.
  설정은 `settings.json`, 로그는 `logs`, 실행 이력은 `reports`에 저장합니다.
- 구버전 실행 파일 감지와 설치 식별자는 유지했습니다. 런처를 설치 프로그램으로
  잘못 선택하지 않도록 업데이트 파일 판별을 보강했습니다.
- 설정·로그·대체 결과 보고서 폴더의 권한 오류가 발생해도 다른 작업 폴더로
  임의 우회 저장하지 않도록 수정했습니다.
- 설치 설계는 `installer/`, 빌드·서명·런처는 `scripts/`, 아이콘 원본은 `assets/`로
  정리하고 중복 아이콘과 오래된 명세 사본을 제거했습니다. 관련 문서도 갱신했습니다.
- 빌드·서명을 한 파이프라인으로 통합했습니다. 공인 인증서, SHA-256, RFC 3161
  타임스탬프를 사용하며 Windows Authenticode 및 SignTool 검증을 통과한 파일만 공식 배포합니다.

## 업데이트 전 확인

이전 `IntegratedDataTool` 또는 `%LOCALAPPDATA%\FileOps`의 설정·로그·예약 이력은
자동 이전하지 않습니다. 사용자가 요청한 새 설정 방식입니다. 언어, 작업 그룹, 예약,
메일 설정을 다시 지정해야 하며 처음에는 예약 실행이 꺼져 있습니다.

사용자 지정 위치에 설치하면 실제 실행 파일 옆의 `UserSetting`을 사용합니다.
프로그램 제거 시 사용자 데이터는 보존합니다. 기존 설치 폴더를 통째로 삭제하지 않습니다.
VBA 등 외부 실행 도구에서 실행 파일 이름을 직접 지정한다면 `App005_FileOps.exe`로 바꿔 주세요.

## 검수 및 범위

- 자동 회귀 테스트 205개, Python 정적 컴파일, 의존성 검사, Ruff 검사를 통과했습니다.
- 앱·런처·설치 프로그램 각각의 서명·타임스탬프와 배포 체크섬을 검증합니다.
- 자동 검증은 깨끗한 PC의 설치·업그레이드·바로가기·자동 시작·제거 및 실제 Office
  변환 검수를 대체하지 않습니다. 이번 배포에서 별도 PC의 전체 수동 검수는 수행하지 않았습니다.
- 디지털 서명은 게시자와 파일 무결성을 확인합니다. 모든 PC에서 SmartScreen이나
  조직 보안 정책 경고가 사라지는 것을 보장하지 않습니다.
