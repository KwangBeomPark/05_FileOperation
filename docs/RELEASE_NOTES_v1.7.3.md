# FileOps Hub v1.7.3

- **Run Tasks:** The task list has more room in compact windows. Detailed logs can be opened below the list; copy, export, and other log actions are grouped in one menu.
- **Folder Sync:** Set up folders before selecting the sync mode, with less common settings under More options. Open an incomplete group directly. Cancelling a preview no longer shows an error, and an outdated approval requires a fresh preview.
- **Convert Files:** The source-handling warning wraps fully in Korean, English, and Polish. The screen highlights the next action based on which inputs are ready.
- **Manual execution:** Run Tasks and Convert Files use one preparation window. Final approval and the pre-execution recheck remain separate, and scheduled runs still do not show confirmation pop-ups.
- Updated help in Korean, English, and Polish. Sync scope, file disposal policies, and scheduling rules are unchanged.
