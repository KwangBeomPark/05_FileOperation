# 실행 전 변경 요약

## 사용 방법

통합 작업 실행과 동기화·EML·PDF·OCR·파일 변환의 **수동 실행**에서 작업 시작 전에
공통 요약 창이 나타납니다. 이번 변경은 소스 기준이며 설치된 EXE를 자동 교체하지 않습니다.

1. 복사·변환 대상·OCR/이름 변경·백업 이동·영구 삭제 등의 예상 건수를 확인합니다.
2. 표에서 작업별 원본과 저장·이동 위치를 확인합니다. 긴 경로는 마우스를 올려 전체를 봅니다.
3. 빨간 경고가 있으면 원본 이동·삭제·TXT 덮어쓰기 등의 의미를 확인하고 확인란을 선택합니다.
4. `확인한 작업 실행`을 누릅니다. 파일 상태를 한 번 더 분석하고, 달라졌으면 실행하지 않고
   새 요약을 확인하도록 안내합니다. `취소`하면 작업용 폴더를 만들거나 변환·복사 작업을 시작하지 않습니다.

한국어·영어·폴란드어는 앱의 선택 언어를 따릅니다. 위험 동의는 매번 새로 받으며 저장하지 않습니다.
기존 작업 흐름·원본 처리 정책·외부 의존성 점검을 대체하거나 새 삭제 권한을 부여하지 않습니다.

## 위험 안내

- 동기화의 구버전 보관이 꺼져 있으면 원본은 **휴지통 없이 영구 삭제**될 수 있습니다.
  현재 예상 삭제 건수가 0이어도 이 정책을 별도로 경고합니다.
- 변환 후 원본 백업은 `Original Backup` 이동으로 표시합니다. 교체 모드는 검증 후 휴지통,
  실패 시 영구 삭제 가능성을 표시합니다. 통합 실행의 기존 교체 금지와 예약 백업 동의는 유지합니다.
- OCR 텍스트 저장은 원본 이미지와 같은 이름의 TXT를 만들며, 이미 있으면 덮어쓸 수 있습니다.
  이번 단계에서는 그 동작을 바꾸지 않고 대상과 경고·확인 항목에 포함합니다.
- 기존 변환 결과 경로가 있으면 덮어쓰지 않는다는 경고를 표시합니다. 해당 파일은 실행 시
  실패할 수 있으므로 다른 저장 위치로 바꾸려면 취소하세요.

## 예상값과 실제 실행의 차이

- 건수는 **작업 또는 입력 파일** 기준입니다. 한 PDF의 여러 페이지를 결과 파일 수로 미리 계산하지 않습니다.
- OCR 이름, 생성 이미지 수, 고유 백업 이름, 앞 단계 결과를 받는 OCR 대상 수는 실행 중 결정될 수 있습니다.
  확정되지 않은 값은 0으로 단정하지 않습니다.
- 동기화 그룹·여러 기능은 순서대로 실행되므로 앞 단계의 변경이 후속 단계 입력에 영향을 줄 수 있습니다.
  요약은 현재 상태의 예상이며 실제 실행 계획을 잠그거나 재설계하지는 않습니다.
- 분석은 파일 내용을 변환하지 않고 기존 동기화 dry run과 파일 메타데이터를 사용합니다.
  확인 후 재검사도 메타데이터 기반이며 내용 해시 검사·파일 잠금·완전한 트랜잭션은 아닙니다.
  실행이 시작된 뒤 외부 프로그램이 파일을 바꾸는 상황까지 막는다고 보장하지 않습니다.
- 화면 표는 처음 200행까지 표시하며 집계·재검사에는 전체 항목을 포함합니다.
  한 번의 분석은 최대 30초, 관찰 경로는 최대 100,000개입니다. 읽기 실패나 분석 미완료를
  '변경 없음'으로 처리하지 않습니다. 범위를 줄이거나 네트워크/폴더 접근 상태를 확인하세요.

## 예약 실행

확인 팝업을 띄우지 않고 예상 집계와 원본 처리 정책을 로컬 진단 로그에 기록합니다.
분석을 완료하지 못하면 그 사실을 경고로 기록하고 **기존 사전점검·예약 동의 기준**으로 계속합니다.
새 요약 기능 때문에 이미 설정한 예약 실행을 중단시키거나 새 권한을 자동 승인하지 않습니다.
사용자가 수동 요약을 확인 중인 동안 예약 시작은 잠시 미루며 시작 실패 횟수를 늘리지 않습니다.

## 검수 및 후속 제안

핵심 검사: 미리보기 중 원본/출력 쓰기 금지, 동기화 영구 삭제와 백업 구분, 충돌본 보존,
기존 TXT 덮어쓰기 노출, 앞 단계 결과 수 미확정, 화면 밖 항목 집계·변경 감지,
모든 수동 진입점에서 취소 시 워커 미생성, 승인 후 워커 시작,
분석 취소·시간 초과·창 닫기, 예약 무팝업 및 확인 중 예약 횟수 보존, 3개 언어입니다.

실제 Office 변환·대규모 공유 폴더 성능·설치본의 frozen 프로세스 실행은 이번 검사 범위가 아닙니다.
화면 검수는 실제 Qt 위젯의 offscreen 렌더이며 설치된 앱의 실사용 검수와 구분합니다.

후속 제안(이번 단계에는 구현하지 않음): OCR TXT를 고유 이름/백업 방식으로 저장해
덮어쓰기 자체를 예방하기, 실행 계획을 고정해 재분석 비용과 단계 사이 차이를 줄이기.
두 개선은 현재 파일 처리 정책을 바꾸므로 별도 단계로 결정합니다.
