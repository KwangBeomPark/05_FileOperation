# FileOps Hub v1.7.1

## Improvements

- Run Tasks now keeps readiness and history in view and groups diagnostics and presets under Manage. Imported workflows refresh the affected screens before reporting success.
- Folder sync identifies the group being edited separately from the groups being run, explains incomplete groups before preview, and keeps the file list and last safety check.
- Manual collection shows the selected group and destination before starting. Manual old-version cleanup has more visible checkboxes and shows the selected file count and move destination.
- Updated Korean, English, and Polish help to match the current screens. Open help from the menu or the current-screen button; there is no dedicated help shortcut.

Ordinary sync still uses an archive folder. Manual old-version cleanup still defaults to the Recycle Bin and can use a separate folder instead. Updating does not change the UserSetting location.
