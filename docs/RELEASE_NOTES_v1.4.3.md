# FileOps Hub v1.4.3 — App05_FileOps

## 변경 사항

- 공식 제품 식별자를 `App05_FileOps`, 설치된 실행 파일 이름을 `App05_FileOps.exe`로 정리했습니다.
  화면 이름은 `FileOps Hub`입니다. 구형 이름은 기존 설치 감지를 위한 호환 목록에서 유지합니다.
- 설치 파일은 `App05_FileOps-Setup_v1.4.3.exe`와 `FileOps-Setup.v1.4.3.exe` 두 이름으로 제공합니다.
  두 파일의 내용과 서명은 동일하므로 하나만 받아 설치하면 됩니다.
- 기본 설치 경로는 `%LOCALAPPDATA%\Programs\FileOps`입니다. 업그레이드는 기존 설치 위치를
  재사용하며, 그 위치의 `UserSetting`에 있는 설정·로그·예약 실행 이력을 보존합니다.
  제거 시에도 `UserSetting`을 삭제하지 않습니다. 외부 구형 데이터 폴더를 자동 가져오지는 않습니다.
- `scripts/build.ps1`과 `scripts/sign.ps1`로 빌드·서명을 통합했습니다. 미서명 개발 파일은
  공식 배포 폴더와 분리하고, 서명·타임스탬프·체크섬 검증을 통과한 세트만 배포합니다.
- 이전 로컬 배포 파일 38개(약 1.87 GiB)를 정리했습니다. GitHub의 과거 릴리즈는 유지합니다.

## v1.4.2에서 업데이트할 때

v1.4.2의 업데이트 프로그램은 새 설치 파일 이름을 인식하지 못합니다. 이번 업데이트는
앱의 **릴리즈 페이지** 버튼 또는 GitHub 릴리즈 페이지에서 설치 파일을 직접 받아 실행해 주세요.
이후 새 업데이트 프로그램은 새 파일 이름을 인식합니다.

기존 설정을 계속 사용하려면 설치 위치를 바꾸지 마세요. 실행 파일 이름 변경으로 기존 작업표시줄
고정 아이콘은 다시 고정해야 할 수 있습니다. VBA 등 외부 실행 도구의 고정 경로도
`App05_FileOps.exe`로 바꿔 주세요. 기존 프로그램을 종료한 후 설치하는 것을 권장합니다.

## 배포 파일과 검수 범위

- 설치 파일 두 개, `SHA256SUMS.txt`, `build-manifest.json`, 선택적
  `App05_FileOps_Launcher_v1.4.3.exe`를 제공합니다.
- App05 변경은 229개 회귀 테스트와 정적 검사, 실제 미서명 패키지 빌드 및 소스·아이콘 비교를
  통과했습니다. Opus 5.5 CLI의 두 차례 독립 코드 검수에서 발견한 차단 문제를 수정했습니다.
- 공식 배포 절차는 앱·설치 파일·런처의 선택 게시자와 타임스탬프, Authenticode Valid,
  SignTool 검증 및 업로드 파일의 SHA-256 일치를 필수로 확인합니다.
- 위 자동 검수는 별도 PC의 신규 설치·업그레이드·자동 시작·제거 및 실제 Office 변환의
  수동 검수를 대체하지 않습니다. 해당 수동 검수는 이번 변경에서 수행하지 않았습니다.
- 디지털 서명이 모든 PC의 SmartScreen 또는 조직 보안 정책 경고를 없애는 것은 아닙니다.
