# FileOps Hub v1.6.1 — App05_FileOps

## 주요 신규 기능 및 개선 사항

### 1. 마스터 작업 통합 및 스케줄러 일원화 (Master Task Unification & Scheduler SSOT)
- **통합 작업(1번 탭) 오케스트레이션 연동**:
  - 파일 수집 동기화(Collect Sync) 그룹들을 1번 통합 작업(`TaskTab`)의 개별 항목(`TaskStep.COLLECT_SYNC`)으로 등록하여 원하는 수집 그룹만 선택해 일괄 실행 가능.
- **단일 진실 공급원(SSOT) 스케줄러 일원화**:
  - 3번 파일 수집 탭의 중복 타이머/스케줄러를 제거하고, 1번 탭의 마스터 스케줄러(`schedule_timer`) 하나로 모든 예약 실행을 통합 제어.
  - 다중 타이머 간 경합 및 동시 쓰기/파일 락 위험 원천 차단.
- **자동 마이그레이션 및 시작 안전성 보장**:
  - 기존 수집 그룹에 설정되어 있던 예약 시간을 1번 탭 마스터 스케줄러로 자동 승계(`migrate_task_selection`).
  - 설정 파일 손상 시에도 메인 앱 구동이 중단되지 않도록 예외 격리 방어 처리.

### 2. 파일 수집 동기화(3번 탭) 결과 테이블 열 헤더 클릭 정렬 (Sorting) 탑재
- **전체 열 오름차순/내림차순 토글 및 인디케이터**:
  - 종류(Kind), 원본(Source), 타겟(Target), 이전 버전(Archive), 결과(Message) 열 제목 클릭 시 오름차순(▲) ➜ 내림차순(▼) 토글.
- **전체 데이터 인덱스 기반 정렬 & 페이징 완벽 연동**:
  - 현재 페이지만 정렬되는 것이 아니라 전체 결과 목록에 대해 인덱스 기반으로 초고속(수 밀리초) 정렬 후 페이징 표시.
  - 대소문자 무시(Case-insensitive) 및 동률 시 원래 순서를 유지하는 안정 정렬(Stable Sort) 지원.
- **뷰 선호도 보존 & 캐싱 최적화**:
  - 페이지 이동 및 언어 변경 시에도 사용자가 선택한 정렬 열과 방향을 자연스럽게 유지하며 불필요한 재연산 방지.
