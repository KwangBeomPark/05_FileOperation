# FileOps Hub v1.7.0

## 주요 변경

- 폴더별로 오래된 파일 버전을 확인하고 선택해 휴지통 또는 별도 폴더로 옮기는 수동 정리 기능을 추가했습니다.
- 폴더 동기화 시 새 파일을 먼저 복사하고 확인한 뒤 기존 파일을 보관하도록 안전성을 개선했습니다.
- 같은 버전의 충돌 및 더 높은 대상 버전은 상황에 따라 보류하고 이유를 표시합니다.
- 확인 대화상자와 옵션, 체크 표시의 가독성을 개선하고 관련 오류 처리와 시험을 보강했습니다.

## 사용 시 참고

- 구버전 정리는 예약 실행되지 않으며, 사용자가 목록을 확인하고 직접 실행합니다.
- 휴지통 방식은 지원되는 PC 내부 저장장치에서 사용합니다. 네트워크·외장 저장장치는 별도 폴더 보관을 이용하세요.
- 기존 설정은 설치 위치의 `UserSetting`에 유지됩니다.
