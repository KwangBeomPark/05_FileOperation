# FileOps Hub v1.5.0 — App05_FileOps

## 주요 신규 기능 및 개선 사항

### 1. 파일 변환(Bypass) 하위 디렉터리 재귀 스캔 및 디렉터리 트리 미러링
- **재귀 스캔 (`recursive_scan`)**: 1단계 직계 파일만 변환하던 한계를 넘어, 하위 모든 폴더를 깊이 탐색하여 일괄 변환할 수 있는 옵션 추가.
- **상대 경로 미러링**: 별도 저장(`Custom Target`) 모드 시 원본의 폴더 계층(`dept/sales/doc.pdf`)을 타깃 폴더에 그대로 유지 및 복제.
- **시스템 디렉터리 및 루프 방어**: `Original Backup`, `.git`, `.svn` 등 시스템 폴더 자동 제외 및 Windows Directory Junction/Symlink 무한 루프 탈출 방어.

### 2. PDF 독립형 HTML 오프라인 웹 뷰어 (.html / Dual Output) 지원
- **사내 보안 아카이브 업로드 호환**: PDF 직접 업로드가 차단된 사내 보안/아카이브 환경에서 ZIP 다운로드 후 압축 해제의 불편함을 해소.
- **원클릭 브라우저 열람**: Base64 Blob 기반으로 외부 의존성(인터넷/C 라이브러리) 없이 단일 파일로 완전 독립 실행되는 오프라인 웹 뷰어 생성.
- **브라우저 네이티브 다중 페이지 인쇄 (`Ctrl+P`)**: 새 탭 네이티브 PDF 렌더링으로 Chromium 교차 출처 제한 없이 고화질 다중 페이지 인쇄 완벽 지원.
- **다국어 자동 감지**: 브라우저 언어에 따라 한국어, 영어, 폴란드어로 UI 문구 및 안내 뱃지 자동 전환.

### 3. Zero/One-Click 생산성 UX 혁신
- **즉시 자동 스캔**: 폴더 선택 또는 드래그 앤 드롭 시 별도 스캔 버튼 클릭 없이 즉시 파일 목록 분석.
- **0ms 인메모리 필터링**: 파일 크기 사전 캐싱으로 콤보박스 변경 시 디스크 I/O 없이 100% 인메모리로 실시간 재렌더링.
- **결과 폴더 원클릭 열기 (`[📂 결과 폴더 열기]`)**: 변환 완료 후 탐색기 창을 즉시 호출.
- **테이블 더블클릭 브라우저 미리보기**: 변환된 행을 더블클릭하면 생성된 HTML 웹 뷰어를 기본 웹 브라우저에서 즉시 실행.
- **용량 전/후 비교 정보 뱃지**: 원본 총량 대비 출력물 총 용량 및 절감률(`XX MB → YY MB (-ZZ%)`) 실시간 표기.

### 4. 백그라운드 완료 알림 및 안전성 강화
- **작업 표시줄 깜빡임 (`QApplication.alert`) & 시스템 차임벨 (`winsound`)**: 대규모 파일 변환 중 다른 창을 보고 있거나 앱이 최소화되어 있을 때 완료를 즉각 인지할 수 있도록 시각/청각 알림 제공.
- **실행 중 D&D 안전 잠금**: 변환 진행 중 드래그 앤 드롭으로 인한 작업 꼬임 차단 및 단일 파일 드롭 시 부모 폴더 자동 채택.
- **대용량 PDF 보호**: 50MB 초과 대용량 PDF의 무리한 인라인 변환 방지 및 트랜잭션 무결성 확보.
- **업데이터 환경변수 정리**: 업데이트 설치 후 자동 재실행 시 Python DLL 로드 오류 방지 (`_PYI_*` 환경변수 리셋).
